## Что осознанно оставлено как есть

- **Ссылки внутри предложений** (`.sec-note a`, строка «Удобнее написать самой?») — высота 21–23px. WCAG 2.5.8 прямо исключает ссылки внутри текста; увеличить их без потери типографики нельзя.
- **Ссылки в верхнем меню на десктопе** — высота 34px (норма AA 24px соблюдена); для мыши этого достаточно, укрупнять за счёт высоты хедера не стал.
- **Подписи «БЫЛО / СТАЛО»** — 13px заглавными: контраст приведён к норме, размер сохранён как осознанный акцент иерархии.
- **Изображения в JPEG.** Перевод в WebP/AVIF даст ещё ~30–40% веса, но потребует второй формат и `<picture>`; текущие 246 КБ на два фото — приемлемо. Следующий шаг по производительности, не дефект.

## Как повторить аудит

```bash
python -m http.server 5174            # в корне проекта
node qa/audit.js                      # глубокий аудит (отчёт также в qa/audit-report.txt)
node qa/measure.js                    # висячие строки, ряды сеток, высоты тарифов
node qa/shots.js                      # скриншоты секций desktop/mobile
python tools/validate.py              # структура, файлы, H1–H3, связки JS ↔ HTML
```

Перед первым запуском: `cd qa && npm install puppeteer-core`.
