# Лендинг бизнес-коуча Айгерим Сериковой

Одностраничный сайт на чистом HTML/CSS/JS — без сборки, фреймворков и внешних библиотек.
Открывается двойным кликом по `index.html`, грузится быстро, легко правится в любом редакторе.

## Структура файлов

```
index.html           — весь контент и структура (H1–H3, мета-теги, schema.org: услуга, цены, FAQ)
privacy.html         — политика обработки персональных данных (нужна для рекламного трафика)
404.html             — страница «не найдено» в стиле сайта (Vercel отдаёт её автоматически)
styles.css           — вся вёрстка, цвета, адаптив (переменные в :root в самом верху)
script.js            — меню, анимация появления, FAQ, отправка заявки в WhatsApp
manifest.webmanifest — установка сайта на домашний экран телефона
vercel.json          — кэширование ассетов и заголовки безопасности
robots.txt           — правила для поисковых роботов
sitemap.xml          — карта сайта для Google и Яндекс
assets/
  hero-portrait.jpg / .webp      — фото hero-секции (1000×1500)
  hero-portrait-640.webp         — облегчённая версия для телефонов
  about-portrait.jpg / .webp     — фото в секции «Обо мне» (900×1350)
  about-portrait-560.webp        — облегчённая версия для телефонов
  og-image.jpg                   — превью ссылки в соцсетях и мессенджерах (1200×630)
  favicon-32.png · apple-touch-icon.png · icon-192.png · icon-512.png
favicon.ico          — иконка сайта в корне (её ищут браузеры и сервисы сами)
tools/
  validate.py        — проверка структуры, файлов и связок JS ↔ HTML
  make_assets.py     — пересборка иконок, OG-картинки и WebP из исходных фото
  prep_images.py     — сжатие исходных фото
qa/                  — скрипты аудита и скриншоты (в репозиторий не попадают)
```

## Как менять контент

Открой `index.html` в любом текстовом редакторе и ищи по комментариям-разделителям:
`<!-- ============ 1. HERO ============ -->` … `<!-- ============ 8. ФИНАЛЬНЫЙ CTA + ФОРМА ============ -->`.
Каждая секция подписана — правится как обычный текст, разметку трогать не нужно.

| Что менять | Где искать |
|---|---|
| Заголовок и подзаголовок hero | секция `1. HERO`, тег `<h1>` и `<p class="lead">` |
| Цифры в блоке доверия | `class="stat-strip"` и карточки `float-card` |
| Портреты клиентов | секция `2. ДЛЯ КОГО` — 5 карточек `<article class="card">` |
| Шаги работы | секция `3. КАК ПРОХОДИТ РАБОТА` — `<li class="step">` |
| Кейсы и отзывы | секция `4. РЕЗУЛЬТАТЫ` — `class="case"` и `class="quote"` |
| Текст «Обо мне» и факты | секция `5. ОБО МНЕ` — `<p>` и список `class="facts"` |
| Цены и состав пакетов | секция `6. ФОРМАТЫ И ЦЕНЫ` — `class="plan"`, `<ul class="plan-list">` |
| Вопросы FAQ | секция `7. FAQ` — каждый вопрос в `<details class="faq-item">` |
| CTA, контакты, подвал | секция `8. ФИНАЛЬНЫЙ CTA + ФОРМА` и `<footer>` |

## Что уже готово к запуску

- **SEO:** `title` и `description`, canonical, Open Graph и Twitter-карточка с превью `assets/og-image.jpg`, микроразметка schema.org (`ProfessionalService` с тремя предложениями и ценами + `FAQPage`), `robots.txt` и `sitemap.xml`.
- **Иконки:** `favicon.ico`, PNG 32×32, `apple-touch-icon.png` и иконки 192/512 для установки сайта на домашний экран (`manifest.webmanifest`).
- **Производительность:** hero-фото в WebP (46 КБ вместо 124 КБ) с `srcset` под мобильный, `preload` + `fetchpriority="high"` для главного изображения, ленивая загрузка второго фото, один CSS и один JS-файл без библиотек.
- **Безопасность и кэш:** `vercel.json` — заголовки `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` и кэш ассетов на 7 дней.
- **Юридическое:** страница `privacy.html` с политикой обработки данных, ссылки на неё из формы и подвала, страница 404.
- **Доступность:** контраст мелких подписей ≥5:1, зоны нажатия ≥43px, фокус-обводки, закрытое мобильное меню вне табуляции, поддержка `prefers-reduced-motion`.

## Что заменить перед публикацией

1. **Контакты.** По всему проекту встречаются тестовые данные — замените их:
   - телефон `+7 777 123 45 67` и номер в ссылках `wa.me/77771234567` (в `index.html`, `script.js` — константа `WHATSAPP_PHONE`);
   - Telegram `t.me/aigerim_coach`;
   - e-mail `hello@aigerim.coach`.
2. **Домен.** Сейчас в проекте указан демонстрационный адрес `https://coach-five-flax.vercel.app/` — он живёт в `link rel="canonical"`, `og:url`, `og:image`, `twitter:image`, в двух блоках schema.org, в `privacy.html`, `robots.txt` и `sitemap.xml`. После покупки домена замените его во всех перечисленных местах одной операцией поиска-замены и обновите дату в `sitemap.xml`.
3. **Данные владельца.** В `privacy.html` указано имя «Серикова Айгерим» и демо-контакты — сверьте с реальными данными (для запуска в РК, возможно, понадобится ИП/ИНН в реквизитах). Текст политики составлен под реальную механику сайта (форма → WhatsApp, без cookies и аналитики), но перед рекламным трафиком его стоит показать юристу.
4. **Фото.** Свои снимки положите в `assets/` под теми же именами — тогда HTML править не нужно. Другие имена — поменяйте пути в `src` и обязательно обновите атрибуты `width`/`height` (это защищает от «прыжков» страницы при загрузке). После замены фото пересоберите производные версии:

   ```bash
   python tools/make_assets.py   # пересоберёт WebP, иконки и OG-картинку из новых jpg
   ```
4. **Кейсы и отзывы.** В файле сейчас правдоподобные примеры с изменёнными именами. Перед публикацией замените их на реальные и получите письменное согласие клиенток на публикацию — включая цифры дохода.
5. **Цены.** Проверьте актуальность сумм в тенге и условия рассрочки.
6. **Политика конфиденциальности.** Форма не отправляет данные на сервер (заявка уходит в WhatsApp), но для платного трафика в РК и ЕС добавьте страницу политики обработки персональных данных и ссылку на неё рядом с формой.

## Как это работает технически

- **Заявка.** Форма собирает имя, контакт, формат и комментарий, открывает WhatsApp с готовым текстом (`wa.me`) и на всякий случай копирует тот же текст в буфер обмена — если окно мессенджера не открылось, заявку можно вставить в Telegram или письмо. Бэкенд не нужен. Если нужна запись в CRM или на почту — замените обработчик `form.addEventListener('submit', ...)` в `script.js` на `fetch()` к вашему эндпоинту или подключите сервис вроде Formspree/Tally.
- **Кнопки тарифов.** У каждой ссылки тарифа стоит `data-plan="..."` — при клике в форме автоматически выбирается нужный формат, и человек попадает к форме.
- **Доступность.** Есть skip-link, `aria`-атрибуты, фокус-обводки и поддержка `prefers-reduced-motion`.
- **Производительность.** Изображения отдаются в WebP (46 КБ и 52 КБ) с JPEG-фолбэком и `srcset` под мобильный, hero-фото предзагружается с приоритетом, второй снимок — ленивый. Один CSS-файл, один JS-файл, шрифты Google с `display=swap`.

```bash

```

Деплой — любой статический хостинг: Vercel, Netlify, Cloudflare Pages, GitHub Pages.
Для Vercel достаточно перетащить папку в панель проекта или подключить репозиторий (framework preset: **Other**, build command пустой, output directory — корень).

## Типографика: правила, чтобы не было «висячих» строк

Одно слово на последней строке абзаца или заголовка выглядит неряшливо, поэтому в проекте действуют три правила:

1. **Короткие строки.** Тексты написаны так, чтобы строка помещалась целиком. Формулировки в карточках и списках — до ~38 символов.
2. **Неразрывный пробел** (`&nbsp;`) ставится в коротких предлогах и привязанных числах: `за&nbsp;3&nbsp;месяца`, `в&nbsp;месяц`, `90&nbsp;дней`, `45 000 ₸`.
3. **CSS сам подстраховывает:** заголовки — `text-wrap: balance`, абзацы и списки — `text-wrap: pretty` (Chrome, Edge, Safari, Firefox). Это переносит слова так, чтобы на последней строке не оставалось одного короткого слова.

Если меняете текст на длинный — проверьте заново через `node qa/measure.js` (см. ниже), он покажет все «висячие» строки по ширинам.

## Проверка перед публикацией

```bash
python tools/validate.py
```

Проверяет баланс тегов, наличие всех локальных файлов и картинок, структуру заголовков H1–H3 и связку JS ↔ HTML по `id`.

```bash
# локальный сервер + замер вёрстки (папка qa/ в репозиторий не попадает)
python -m http.server 5174
cd qa && npm install puppeteer-core && cd ..
node qa/measure.js
```

`qa/measure.js` открывает страницу в headless Chrome на 9 ширинах (390…1440px) и печатает:

- есть ли горизонтальная прокрутка и какие элементы выходят за экран;
- сколько карточек в каждом ряду сетки (следы вида `.cards-5=3+2` — это ровные ряды 3 + 2);
- высоты трёх тарифных карточек (должны совпадать);
- **висячие строки** — абзацы и заголовки, у которых на последней строке осталось одно слово.

`qa/shots.js` делает скриншоты каждой секции в desktop и mobile для визуального просмотра, `qa/measure.js` дополнительно печатает высоты тарифных карточек.

```bash
node qa/audit.js
```

Глубокий аудит по чек-листу: консоль и failed requests, шрифты, все контактные ссылки (WhatsApp/Telegram/телефон/e-mail), перекрытие якорей липким хедером, открытие всех вопросов FAQ, отправка формы (пустой и корректной — с проверкой собранного сообщения), мобильное меню и Escape, порядок фокуса с клавиатуры, а на 12 ширинах от 320 до 1920px — горизонтальная прокрутка, тач-таргеты меньше 44px, текст меньше 14px и контраст текста по WCAG (норма 4.5:1). Результат дублируется в `qa/audit-report.txt`.

Что уже проверено и закрыто этим аудитом: контраст мелких подписей поднят до 5:1 (`--terra-ink`), ссылки в подвале получили зоны нажатия 43px, закрытое мобильное меню больше не попадает в табуляцию, логотип и кнопка меню не перекрываются панелью, плавающая кнопка WhatsApp уходит, когда открыт блок с формой.
